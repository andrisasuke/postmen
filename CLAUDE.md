## Architecture and constraints

- Vue SFCs use `<script setup lang="ts">`; UI and IPC DTOs live in `frontend/src/types/`.
- `frontend/src/services/desktop.ts` validates bootstrap/menu events and distinguishes browser from native connections; `services/data.ts` validates every data IPC response using Zod.
- `frontend/src/stores/settings.ts` validates new shell-only localStorage preferences and follows system theme changes.
- `frontend/src/components/` contains layout and UI primitives. CSS variables in `styles/tokens.css` derive from the pinned baseline.
- `frontend/src/fixtures/` and `features/ReferencePreview.vue` are DEV-only. `?fixture=reference` preserves M1 visual data; `?fixture=workspace` is a labeled memory/localStorage CRUD test double; `?fixture=execution` adds HTTP simulations; `?fixture=visual` uses the actual WorkspaceApp with deterministic in-memory data/executions. None proves actual SQLite/HTTP/native IPC; all four are excluded from production.
- `src-tauri/src/lib.rs` owns the native menu/command registration. `commands.rs` delegates SQLite work to `db/` using spawn_blocking; request+rows save atomically with revisions. Capabilities allow only commands needed by the local main window; do not add broad filesystem/shell/network permissions.
- M3 HTTP lives in `src-tauri/src/execution/`: shared TLS client, prepare/execute/cancel protocol and per-execution cancellation. Do not hold the database mutex during network I/O or render server content as active HTML. Preserve 1 MiB decompressed preview, 100 MiB streaming file limit, bounded formatting, duplicate headers and safe credential-free diagnostics. Cross-origin redirects stop at 3xx; no automatic proxy/cookie jar.
- New database: `app_data_dir()/postmen.sqlite3`, identifier `com.postmen.desktop`. Current Tauri v1→v2 schema upgrade only; no migration, import, fallback, reading, or deletion of the legacy Dioxus database. No login/user migration.
- Dioxus source/config and Dragon Ball assets were removed in M1 at the user's explicit request. Their recoverable external backup is documented in M1, not a second supported runtime. Preserve gzip/deflate/brotli in M3. M2 implements auto-open Body for saved requests with a body unless a saved tab view takes precedence.
- `native-smoke` is an opt-in macOS QA feature. It validates explicit postmen-m2-*, postmen-m3-* or postmen-m4-* temporary output/database directories before opening the DB, and is absent from ordinary builds. `npm run test:native -- --m4-report` runs the M3 regression against M4: two native processes, shared temporary DB/window state and loopback HTTP/TLS. `npm run test:native:visual` captures actual SQLite/HTTP/WKWebView. Both use an explicit random UUID WebKit data store: a unique bundle identifier alone did not isolate preferences reliably. QA-only manual window construction works around the locked tauri-utils config-macro dataStoreIdentifier array-generation issue; ordinary builds are unaffected. The historical M2 runner is not the current verification command. Do not ship a smoke build.
- Fresh macOS window normalization only corrects the configured default when no saved window state exists and the actual size is within 1px of that default; never override restored/user/display-clamped dimensions. Current bootstrap IPC schemaVersion is 5 and SQLite user_version is 2; the milestone label remains M4. Historical OS evidence used versions 3/1.
- macOS `macos_input.rs` uses an app-local NSEvent monitor on the main window, routes only the affected shortcuts to the existing modal-aware handler, suppresses repeat Send, and retains the genuine pointer-down for `start_titlebar_drag`. No global monitor or runtime Accessibility/Screen Recording permission. Controls/doubleclick/non-macOS keep standard behavior. Do not reconstruct a drag event from global coordinates.
- macOS `macos_window_state.rs` preserves normal bounds separately from animated Zoom events, captures before Zoom, coalesces move/resize, validates a bounded v1 preference document, restores normal bounds before maximizing and saves by atomic rename. Windows/Linux retain the window-state plugin. No database migration; failed state persistence remains part of the Quit guard.
- UiSelect popups stay in the nearest modal dialog's focus boundary. Scroll only the option list when revealing a selection; scrollIntoView previously moved the workspace and detached the popup at minimum size. Preserve keyboard, disabled, outside-click and rerender stability tests. SplitPanes retains its resolved request width when the sidebar collapses.
- Browser screenshots, native WebView snapshots, and physical OS interactions have separate evidence. Never describe geometric alignment as complete pixel parity.
- OS QA scripts use scoped AXPress/CGEvent on an explicit PostMen QA PID, isolated SQLite/UUID WebKit state and a loopback fixture. DOM is an assertion oracle, not an input substitute. Preserve `os-input/`, `os-input-before-reconnect/` and `os-input-fixed/`; archive to an explicit new destination before a fresh run. `POSTMEN_OS_QA_RETEST=1` selects the fixed evidence folder. Run input drivers sequentially; their lock rejects overlap. Native processes exit via UI Quit; launcher exit code alone is not acceptance. Both old and fixed `results.json.passed` remain false (fixed: hardware blockers only); audit integrity is not full acceptance. Build fixed release with `scripts/package-m4-os.mjs` in `target/os-fixed`, not over the original bundle. Do not ship `native-smoke` or open the legacy DB.
- Historical `designs/` images and `docs/visual-reference/` sources are not runtime assets.
